# ClusterMON tools

## BMC discovery

`discover_bmcs.py` scans connected `/24`-or-smaller IPv4 networks for Redfish BMCs and writes the discovered nodes to `config.json`.

```bash
python tools/discover_bmcs.py
```

For a specific network:

```bash
python tools/discover_bmcs.py --network 172.16.1.0/24
```

It only probes `https://<ip>/redfish/v1/` and requires a valid Redfish response. Self-signed BMC certificates are accepted during discovery because this is a local/factory bootstrap operation.

### Password setup

Passwords are never written to `config.json`.

Set the password in the current shell without putting it in shell history:

```bash
eval "$(python tools/discover_bmcs.py --export-password)"
```

The command securely prompts for the password and emits:

```bash
export CLUSTERMON_BMC_PASSWORD='...'
```

The config generated by discovery points every newly discovered node at that variable.

### Important

The discovery tool does not guess BMC credentials and does not store passwords on disk. It only discovers Redfish endpoints and creates the ClusterMON node configuration.
